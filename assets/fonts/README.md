# Source Sans Pro Fonts

Please download the following TTF files from Google Fonts and place them in this directory:

1. Go to https://fonts.google.com/specimen/Source+Sans+Pro
2. Click "Download family"
3. Extract the following TTF files to this directory:
   - SourceSansPro-Regular.ttf
   - SourceSansPro-SemiBold.ttf
   - SourceSansPro-Bold.ttf

The files should be in this exact directory: `/assets/fonts/`
